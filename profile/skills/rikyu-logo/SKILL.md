# Rikyu Logo

使用 https://rikyu.ai/ 完成 Logo 生成。先发现当前可用的 Rikyu MCP 工具；工具不可用时使用网页。只编写提示词不等于生成完成。

## 品牌简报

从当前项目与用户要求提取品牌名（保留准确拼写）、用途、目标用户、风格、颜色、是否含文字和需要的文件格式。已有信息直接使用。缺少决定设计方向的品牌身份时一次问清；其余信息可用明确说明的默认值继续。

默认制作简洁、可缩小识别的平面标志。优先纯色、少量颜色、清楚轮廓；避免把样机展示图当作 Logo 原文件。用户有明确视觉要求时以其要求为准。先生成一个方向，按反馈迭代，不自动批量消耗额度。

提示词可采用：

> 为「{品牌名}」设计 Logo。产品是{产品与受众}。用于{使用场景}。视觉方向为{风格和核心意象}。颜色为{颜色或允许自由选色}。文字要求：{准确文字或不含文字}。保持小尺寸可识别。输出独立标志，不带产品样机、场景或展示板。希望得到{所需格式及背景}；请以实际支持的导出选项为准。

## 接入与执行

首次接入或工具行为不明时，读取 [接入参考](references/rikyu.md)，再核对当前官方说明与实际工具 schema。

1. 发现当前已加载或可搜索的 Rikyu 工具。优先使用其项目、生成、状态查询和导出能力。按真实名称与 schema 调用，不臆造 `generate_logo`、API URL 或参数。MCP 已配置不等于已认证或请求成功。
2. MCP 不可用时，打开官网并依据当前页面操作。浏览器工具须先读取自身文档，再读取页面状态；控件定位来自实际页面。不要借用营销演示的结果作为用户产物。
3. 遇到登录、验证码、账号选择或付费升级时保留当前状态，说明用户需要完成的具体动作。不要收集密码、提取 Cookie 或自动购买。已授权生成且现有额度足够时直接继续，不重复询问许可；不把“Start for free”当作所有账号、MCP 或商用都免费。
4. 在目标项目内提交简报。记录真实返回的任务或设计标识。异步任务只按实际状态继续；提交超时且结果未知时先查询原任务或项目，避免重复生成及重复扣费。没有可核验状态时报告未知。
5. 查看实际结果。检查品牌拼写、意象、轮廓、小尺寸识别和背景。需要修订时引用已有设计，说明应保留与应改变的内容，减少无关变化。
6. 从真实导出入口或服务返回链接取得文件。格式和透明背景必须按实际文件验证。PNG 不能改扩展名冒充 SVG；SVG 内嵌位图也不能宣称为纯矢量。缺少所需格式时保留原始文件，说明缺口；不擅自换生成器。

## 交付

文件优先保存到用户指定位置，其次是当前项目合适的品牌资源目录。无明确项目归属时遵循环境的统一资源目录约定；同名文件不直接覆盖。

检查文件可打开、内容与预览一致、尺寸及格式符合用途。需要透明背景时核对 alpha 和实际透明区域，不能仅凭棋盘格预览判断。商用任务核对当前账号方案与适用条款；未知时说明未核验，不保证商标注册或独占性。

交付实际文件链接及简短设计说明。服务未接通、生成失败或仅有提示词时明确报告未生成；已有图片但导出未完成时分别说明。若只进行了文本场景评测，不能声称 Rikyu 真实生成或下载已验收。
