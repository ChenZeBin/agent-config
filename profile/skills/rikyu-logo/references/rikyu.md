官方说明 MCP 可以保存、创建、读取、导出及整理设计；尚未核验公开工具名和参数。不要预写假 API、硬编码任务状态枚举或推测下载链接。对 MCP URL 做普通网页 GET 不能代替 MCP 握手及工具查询。

## Logo 与导出

[官方产品演示](https://rikyu.ai/) 展示从自然语言生成 Logo，再复用该设计。首页内嵌工作室文案提供 PNG 与 SVG 导出说明：PNG 保留透明度；SVG 可编辑且文字转轮廓。这些是官方能力声明，不证明每种生成结果、账号或 MCP 工具都支持相同导出。

执行时以所选设计实际可见的导出选项和下载文件为准。SVG 要检查实际矢量内容；PNG 要检查实际透明度。官网演示资源不能作为用户新生成的 Logo 交付。
