# Typeless 原生界面重采样

目标是更新可复用视觉与交互证据，保留近白主表面、软灰选中、细边框、柔和阴影与目标产品的深中性主动作默认。没有有效新证据时沿用旧证据的版本边界；不创造绿色品牌，不声称建议色值来自 Typeless。

## 1. 开始与停止

- 先核对技能源、发现路径是否软链、所有者和 dirty 状态；保存本次要改文件的哈希。另一个任务写同文件时先协调，写入前再核验。不要用整目录同步覆盖其他修改。
- 用已安装 App 的 `Info.plist` 只读核对安装版本/构建号；打开关于页才支持当前运行窗口的版本。两者分别留证，不以安装包替代运行核验。
- 仅取得 `Info.plist` 时，交付中明确写“安装版本已核对，运行版本未核验”；即使 GUI 锁屏，也不能省略运行版本的状态。
- 查已启用工具与 App 窗口。使用支持的定向窗口观察/API；开始前确认 App、工具版本、事件范围和桌面占用。同桌面有锁屏、认证、权限或其他测试时停止受影响采样，不抢窗口、不关闭提示、不换全局鼠标键盘绕过阻塞。系统密码和屏幕权限由用户处理。
- 本协议只读与非持久交互：不录音/听写，不给第三方发送文本，不访问账户、私人听写历史、统计、词典或用户内容，不切换外观、声音、快捷键或其他偏好，不点更新/登录/外链。取图若不能排除个人内容，停止该页；脱敏副本不能替代原始取证，须注明裁剪/遮盖。
- 只能访问截图/AX 时使用这两类证据；即使 App 使用 Web 技术，也不假定 DOM 可达。不启动调试、注入、不新开远程调试端口或新增持久访问。确有用户授权且有受支持 Web DOM 工具时，DOM 值单列，仍须核对实际状态和呈现。

## 2. 建立采样清单

复制 [证据模板](evidence-template.md) 到任务本地私有材料目录；原始截图不直接写入可公开 Skill。分配唯一 snapshot ID，记录 UTC 时间、App 安装与运行版本、macOS、工具/API版本、主题实况、语言、逻辑窗口尺寸、截图像素、缩放与色彩配置。拿不到的字段填 `null` 并解释，不能反推 Retina=2 或将图片像素当 pt。

| 页面 / 组件 | 本协议允许的状态与动作 | 不做或另需授权 |
| --- | --- | --- |
| 关于 | 当前版本文字与无个人内容区域；观察后返回原页 | 更新检查、外链或安装 |
| 设置 | 主表面、导航选中、分组行、边界、主次控件；滚动可见范围 | 开关偏好、输入/保存快捷键、查看账户/历史 |
| 语言选择器 | 在确认打开不会写值后观察 closed/open、焦点、已有 selected；无提交的中性搜索与 empty 若确有该组件可观察 | 点击候选、增删/排序、立即保存实验；不假定 Escape 撤销 |
| 二级说明弹窗 | 在入口已核对后仅 open/close；分别观察退出层级和焦点返回 | 不点击添加动作或修改配置 |
| 交互与主题 | 在已显示界面观察非持久 hover/focus，当前主题实况 | pressed 可能激活动作，dark/off/disabled/loading/error 不为取样而人为触发持久或网络行为 |

每次动作后重新观察，按当前工具契约取得新 AX 索引；记录前后组件、画面与实际退出路径。页面不可达、动作性质不明或当前只显示私人内容时标 `blocked` / `not_sampled`，不尝试填满状态表。

本协议不验证持久化：旧 2.8.0 的立即保存、暗色、off、加载、三语言上限等仍属于历史记录，并不因本次未采而抹除，也不因 App 已升级而自动成为 2.8.1 通过。当前主题不是 dark 时记录 dark 未采，不改变偏好。

## 3. 从原始观察到 token

用 [tokens.schema.json](tokens.schema.json) 记录。示例 [tokens-example.json](tokens-example.json) 只展示分层和未知，不是完整或现行基线。

1. **原始观察**：截图/AX/声明/运行测量分别有 ID、摘要、采集条件与版本。AX 能说明其实际暴露的角色、名称、selected/enabled；不能据此猜字体或阴影。截图像素只支持该图中的颜色/几何候选，透明叠层、抗锯齿、缩放与色彩管理会影响数值。
2. **候选 token**：留 rawValue 与 value、type、unit、precision、status、sourceIds、confidence及理由。无法确定精确字号/字体/半径/阴影/动画时长，数值为 `null`、精度为 `unknown`；可另记“近白”“圆角明显”等定性观察，或单列目标产品近似建议。源码默认标 `declared`，未核对运行覆写不能标当前实测。
   面向中文读者报告时，将 `unknown` 同时写作“未知（unknown）”，并指出缺少哪种运行测量或声明；不能只留下英文枚举值。
3. **语义角色**：surface.panel、surface.selected、text.secondary、border.control、action.primary、focus、error、chart.category 分开。selected/hover/off/disabled 不因都灰就合并，成功不自动绿；精确值相似也保留角色。品牌身份来自用户已确认要求/资产，频次和预测只是线索。
   未确认的绿色主按钮不能作为 Typeless 官方或当前实测 token。回答目标产品如何落地时，应同时给出可逆的中性深色主动作建议，并把它放在转译建议层，避免只留下否定结论或把建议误入参考基线。
4. **组件与状态**：token 必须带 screen/component/state/theme、observedAppVersion 和适用范围。跨页归类保留成员、各状态证据、冲突与不同上下文，不能把一种弹窗推广到全应用。先覆盖再汇总；重复取同一画面只增加 repeatCount，不增加独立页面/状态数。
5. **置信度**：`low/medium/high` 是理由明确的证据判断，不是百分比。单帧/历史摘要通常只支持局部或定性判断；高置信仍不意味着精确测量。记录 independentScreens、independentStates、repeatCount、limitations；跨页出现不自动升级，冲突和采样失败保留。

排版先认角色/层级，平台系统字体可作为建议，不从截图写“SF Pro 15pt 已提取”。保留原始候选，先按语义和环境分组再比对视觉；不照搬 Dembrandt 的 ΔE < 15、4/8px 节奏或首页优先。

## 4. 差异与验收

先匹配 app、screen、component、state、theme、locale、逻辑尺寸、缩放、色彩与采样方式。版本变化是比较目标，其他条件尽量一致；不一致时注明不可比原因，不能把它写成升级造成变化。字段未知也不能默认一致。

分别列 `changed`、`unchanged`、`incomparable`、`unknown`、`newly_observed`、`not_sampled`。历史建议与当前观察不参加同一实测 diff；低置信候选不删除，移到需复核栏。双侧缺失、全部 GUI 受阻或仅验证安装版本时，无有效视觉基线，不能给零漂移或通过结论。

像素差要有同尺寸/状态对照，逐项看裁切、抗锯齿和叠层；建议值变化只叫转译调整。发布 token 前另在目标产品真实环境捕获主要尺寸截图，复核层级、软灰选中、边框阴影、强调色稀缺及状态可达性。取证成功不等于目标实现验收通过。

动效使用可靠时间轴录屏/帧采集，分别测进入/退出、反向/中断、快速重复与 reduced motion；不能用工具调用耗时计算动画时长或 FPS。依赖默认可能被主题、props 或运行环境覆写；可访问 DOM 时核对最终 computed style 与实际呈现，原生无 DOM 时用受支持运行测量，否则保留未知。不为本次只读采样改变系统减少动态效果设置。
