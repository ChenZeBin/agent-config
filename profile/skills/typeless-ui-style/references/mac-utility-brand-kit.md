# Mac 小工具品牌家族资料

这套资料来自自有 `mac-utility-brand-kit` v0.1 提案，来源阅读记录日期为 2026-09-19。本次只整合可复用资料。没有重新观察 Typeless，也没有完成目标 App 的视觉或原生测试。

## 适用范围与优先级

- 保持主 Skill 的触发边界：FinderRight／超级右键 UI 默认适用；其他产品须明确要求 Typeless 风格。普通极简设计或其他品牌重设计不自动触发。
- 用户明确要求整合或查看这些历史品牌资料时，可以读取本参考；这不授权把整套风格应用到其他项目。
- 用户已确认的品牌和产品结构优先。其次是主 Skill 的来源分类与中性主按钮规则。历史提案只提供可选方向。
- 提案中的蓝绿色、S 标记、示例名称和产品图标色都未获品牌确认。HTML 中的“品牌蓝贯穿界面”是历史概念文案，不能覆盖当前规则。
- `tokens.json` 的 `status: design-proposal` 必须保留。品牌色不是通用原生 UI 前景色、背景色、成功态或操作态。

回答采用条件时，明确说明：历史资料尚未确认；已有的用户确认品牌优先；主 Skill 的中性主按钮默认和颜色来源分类继续有效。将历史提案放在“本次转译建议”的候选来源中，不能把它登记为 Typeless 的“参考观察”。

## 品牌结构与三类图标

采用“母品牌背书＋可区分的产品图标＋原生 macOS 交互”作为可选结构，不把母品牌放大成工作区装饰。

| 角色 | 用途 | 复用边界 |
| --- | --- | --- |
| 公司标志 | 官网、About、支持入口、宣传素材 | 可复用榫合等形状研究，不替换用户已确认标志。S 方案是另一项历史探索。 |
| 应用图标 | Dock、Finder、系统入口 | 保持共同几何语言，每个产品有可辨的功能轮廓。不要只换颜色。圆角底板 SVG 是预览稿；前景层可作为制作输入。 |
| 菜单栏图标 | 小尺寸常驻入口和状态 | 另做简洁单色模板图标。不能直接缩小彩色应用图标或公司标志充当最终菜单栏图标。 |

包内没有可交付的 `.icon`、`.icns` 或 App 构建。使用 Icon Composer 或其他工具交付时，另查当时官方要求，并在真实目标环境检查 Dock、Finder、菜单栏、明暗背景和小尺寸可辨性。

## 原生交互与组件复用

- UI 使用系统语义色、系统文字样式。主按钮、选中态、焦点和成功态须分开定义。未经用户确认，不把历史蓝绿色套到主按钮。
- 间距、圆角、动效时长和窗口尺寸只是在原提案中的起点。它们不是 Apple 强制数值，也不是 Typeless 实测值。按内容和平台行为验证。
- 菜单栏弹窗、单窗口工具、带历史的工作台是三种可选结构。不为小工具强加侧栏。
- 有对应功能时才提供 `⌘,`、`⌘Q`、`⌘W`、`⌘F`。明确说明权限拒绝、离线、空数据、加载、失败和取消后的行为。保留输入；可撤销时提供撤销。
- 可复用资源与组件的候选包括 BrandAssets、DesignTokens、AboutView、SettingsSections、EmptyState、ErrorState、PermissionExplanation 和 SupportLinks。这是模块划分提案，包内没有已经实现的共享 Swift Package。
- 同一品牌家族不等于共享账号、订阅、剪贴板或诊断数据。默认每个 App 独立；跨 App 数据流须另行定义用户意图、授权和边界。不能替换当前工作会话的真实剪贴板来做演示。

## 使用与验证

1. 确认触发范围、目标品牌和所需图标角色。
2. 选取资源。修改时保留“提案”状态，直到用户明确确认。颜色交付仍按主 Skill 分类来源。
3. 在项目内建立自己的实现与资源。不得把复制 SVG、打开 HTML 或静态检查称为 App 已验证。
4. 运行 `python3 scripts/validate_brand_kit.py` 检查本资料包完整性。此检查只覆盖文件、SVG 结构、链接和 tokens。
5. 对实际 App 按项目要求执行原生构建、真实主要尺寸、窄窗口、短高度窗口、键盘、VoiceOver、缩放、减少动态效果等验收。记录执行环境和未测范围。
