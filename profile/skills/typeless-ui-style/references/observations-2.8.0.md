## 必须纠正的过度归纳

1. 蓝色不是所有焦点的固定样式。已见深色轮廓；示例品牌焦点环仍可作为目标产品建议，必须标注转译。
2. 控件不只有一种圆角。表单框、导航选中块、胶囊动作和大弹窗各有角色；具体数值未提取。
3. 功能示意图展示的黑色浮条和菜单不等于实际运行的暗色模式，也不证明浮条的交互和动画。
4. 个性化的数据类别色不属于导航或主按钮强调色；不复制参考应用的统计数字或业务内容到目标产品。
5. 快捷键是行内录入，并非快捷键弹窗。初次捕获待录入态，后续捕获系统保留键错误；没有主动指定新快捷键，错误的实际输入来源未确定，不声称已复现触发条件、成功保存或验证全部冲突。
6. 灰色外观不能证明控件 disabled；截图中的指针附近光晕不能作为界面 hover 或阴影 token 的证据。
