# 小黑：极简但有戏

目标是有叙事和情绪的极简漫画。读者先看见人物在做什么，再读出矛盾；丰富度来自有效细节，而非装饰数量。

## 视觉语言

- 干净纯白背景、黑色手绘线稿。允许主轮廓较粗、细节较细，以及少量排线、接触阴影和黑色填充来增强力度；不铺灰底、不堆纹理、不把人物画成大面积实心黑块。
- 单一强调色默认蓝色 `#2563EB`。可用于关键物件的完整色块或一个语义一致的区域，不必只点一小处。色块服务视线与含义，不能为了热闹把所有东西涂蓝；不用第二种彩色、渐变或彩色阴影。
- 默认横版 16:9。根据故事安排偏置、斜向动势、近大远小与疏密对比，不默认每张都把等大物件居中排成图标。留出足够空白隔开主次；不固定主体只占一半或要求机械留白比例。
- 无角色参考时：原创通用圆头人物，一小撮短发、白色上衣、清楚的手脚。眼睛、眉毛、嘴和身体重心共同表现费力、迟疑、释然等情绪，必要时适度夸张。没有用户参考，不声称复现某个已有“小黑 IP”。
- 角色亲自推动、选择、修补、搬运或操作核心物件；动作有明确受力、接触和方向，不能只站在旁边指一下。保持肢体完整和动作物理关系可读。

## 让细节解释观点

- 围绕一个核心矛盾选一两处叙事细节，例如磨损体现消耗、积累体现时间、物件的前后状态体现结果。每处细节都应回答“它帮助读者理解了什么”。
- 情绪符号和动作线只在动作需要时使用；不能每张自动添加汗滴、星星、光芒、箭头或碎纸。
- 主动作最醒目，叙事细节第二层，背景最轻。缩到文章实际阅读宽度时，人物表情、关键物件和关系仍可辨认；小细节看不清也不应损害主旨。
- 默认无标题、水印、品牌名、装饰数字。能不用字就不用；必要中文标注最多三处，每处尽量不超过六字。明确的用户文字要求优先并逐字检查。
- 避免卡片堆叠、仪表盘、复杂网络箭头、霓虹科技背景、立体商业渲染和无意义装饰。不得把“有张力”解释成满画面、花哨或机械地增加道具。

## 同一观点的升级示例

观点：忙得很久，却没有前进。

小黑在固定于地面的跑轮里奋力跑，眉毛紧绷、嘴张开、身体前倾。轮架固定螺栓明确可见。近处几只磨破的鞋说明已经消耗很多时间与力气；远处一面完整蓝色色块的目标旗，与轮子之间留下长段空白。近大远小、人物的费力与旗子的静止形成对比。无文字。

鞋和汗只属于这个场景；其他文章应从各自观点寻找细节，不复用成装饰套餐。目标仍在远方，不能画成跑轮正滚向旗子。

## 单图提示词骨架

```text
用途：正文极简漫画配图。
核心意思：[一个重点]
场景与矛盾：[具体物件和视觉关系]
角色动作与情绪：[接触、受力、姿势、表情]
叙事细节：[一两处，每处说明其语义；无必要则省略]
构图：[比例、视觉重心、大小/远近/疏密对比、留白]
风格：纯白背景、黑色手绘线稿、主次线宽，单一蓝色 #2563EB；关键物件可用完整蓝色色块。
角色：[用户参考身份，或原创圆头短发白衣人物]
文字：[准确引号内原文，或无任何文字]
约束：[关键语义、不可出现的错误关系、排除无关装饰]
```

明确的用户参考及风格要求始终优先；要求安静、克制、纯线稿、无道具或其他配色时，不强行添加夸张情绪和色块。
