# 实际图片检查

逐张观察最终输出，不能只检查提示词：

1. 不看正文是否能辨认关键动作？图有没有把观点表达成反义或错误因果？
2. 人物是否实际操作核心物件，而非站在角落？身份与参考是否一致？
3. 是否遵从本次有效风格：默认白底黑线单一蓝色，或用户覆盖后的配色？
4. 是否只讲一个重点，有足够留白，主要物件在目标阅读尺寸仍清楚？
5. 是否出现多余标题、乱码、拼错标注、水印、畸形肢体或不必要装饰？
6. 图片链接/文件是否真实存在，数量与用户要求是否一致？

7. 默认漫画风下，表情和身体重心是否共同表达情绪？角色有明确接触和受力，还是只摆姿势？用户要求克制时不以夸张为硬性指标。
8. 叙事细节是否说明同一观点的时间、代价或结果？删掉无关道具、惯用汗滴和装饰线，避免为了“不素”而堆满。
9. 大小、远近、疏密或动静是否形成清楚的视觉层次？强调色是否有语义和足够分量，而非到处点蓝？缩到阅读尺寸，主动作仍应一眼可读。

指出不合格的具体区域与修改目标，修改后重新打开看。不能将未查看的图片标记为检查通过；不能将“图已生成”当作“Skill 已评测”。
