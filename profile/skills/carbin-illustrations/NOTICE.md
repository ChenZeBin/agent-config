# 来源与改编

本 Skill 的内容理解、配图规划、角色参与核心动作、逐张生成和 QA 工作流改编自 Ian 的 **Ian Xiaohei Illustrations**。

- 上游：https://github.com/helloianneo/ian-xiaohei-illustrations
- 参考版本：`91b560849e8f883922cc2fa8a358a668caa94105`
- 本版更名为 `carbin-illustrations`，改为中文简洁流程、通用空心线稿角色与单一蓝色强调；未复制上游示例图片或小黑角色。
- 教程来源：https://x.com/Morry4AI/status/2098318284756316510
