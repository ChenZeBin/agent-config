# 在线 IPA 砸壳引导

默认入口：[在线 IPA 砸壳服务](https://decrypt.34306.lol/)。
项目来源：[macOSAppstoreDecrypter](https://github.com/34306/macOSAppstoreDecrypter)。

## 默认响应

先给可点击的网站链接和简短步骤，不用询问设备型号、越狱状态或 Apple ID 才给入口：

1. 打开网站，按 App 名称或 Bundle ID 搜索目标应用；用户提供 App Store 链接时沿用其中的名称或 App ID，搜索字段是否支持 App ID 以当前页面为准。
2. 核对应用、地区和版本；按页面入口发起解密，或下载已有结果。按钮名称、登录要求、队列和额度以实际页面为准。
3. 等待处理完成，下载 `.ipa` 到本地。只有提供了实际文件或下载证据，才能说已经下载。

用户只要入口时，给链接即可。用户已提供具体 App 时围绕该 App 引导，不重复问已知信息。可使用如下简短表达：

> 去 [在线 IPA 砸壳服务](https://decrypt.34306.lol/)，搜索 App 名称或 Bundle ID，核对版本后发起解密，完成后下载 `.ipa`。你无需自备越狱 iPhone，处理由服务端完成。

## 范围与异常

- 默认任务是引导用户自行操作。只有用户要求打开网站、代操作或下载时，才使用相应浏览器/下载能力；不要因触发本 Skill 自动安装项目、登录、提交解密任务、上传文件或购买服务。已有明确授权的操作无需重复询问。
- 不要求用户把 Apple ID 密码、验证码发到对话中。网页注册账号和 Apple ID 是不同概念；遇到 Apple ID 凭据要求，提醒核实服务方，不把服务器部署文档中的账号配置当作访客操作步骤。
- 用户只有本地 IPA 时，明确“是否支持上传现有 IPA 尚待核实”，不要把上传解密当作已支持功能。可先提供网站入口；只有继续操作确实需要时，再询问对应的 App Store 应用或链接。涉及私有包先说明会传给第三方，不能默认上传。
- 未实时访问时，不声称服务当前可用、免费、无需登录或成功率有保证。需要当前状态、价格、按钮路径时再只读查看页面，并区分网页可达与实际解密成功。
- 网站不可用时说明限制，保留原入口和项目来源，建议稍后重试；不编造镜像、下载地址或 API，不自动改成本地安装、降级系统或越狱路线。

## 下载后的边界

- 砸壳解除二进制加密，不会恢复源码，也不保证能直接安装或解锁付费功能；重签名是独立步骤。
- 项目说明及源码存在仅解密主程序的处理模式，内嵌 Framework、插件可能仍加密。用户只要入口时不必展开；用户询问完整性或要做完整逆向时，提示查看任务日志中的 `main-binary-only` 等信息，不能仅凭生成 `.ipa`、页面完成或单一 `cryptid=0` 判定全包成功。
- 若用户进一步授权检查下载文件，应覆盖主程序、Framework、扩展中的相关 Mach-O 和架构切片，区分“加密标记检查”和“已实际验证解密内容”。没有检查就明确未验证。
- 本 Skill 记录的是首选服务及操作方向，不保证域名所有权、运行状态和功能永久不变。
